# PyCallocs - A Python Extension for seamless Interoperability with C

## Building

Assuming you have the necessary dependencies, you *should* be able to build PyCallocs with CMake:

```bash
git clone https://github.com/difcis/pycallocs.git
cd pycallocs
cmake -S . -B build
cmake --build build
```

Please raise an issue if you encounter any problems during the build process.
